# APOGEE project brief

Apogee is the runtime layer that gives autonomous AI agents on 0G a self-custodial smart wallet, programmable spending policies, ERC-7857/ERC-8004 identity, encrypted persistent memory on 0G Storage, agent-to-agent payment rails with on-chain receipts via 0G Chain, a paid skills marketplace, and 0G Compute as the inference backbone. Every billable action emits an on-chain Receipt. The product targets developers building on 0G; UX must feel like Stripe + AWS + Linear.

## Immutable stack

TypeScript 5.5.x, Solidity 0.8.24, Node.js 20.18.x, pnpm 9.12.x, Turborepo 2.x, Next.js 14.2.x App Router, Tailwind 3.4.x, shadcn-style components, framer-motion 11.x, wagmi 2.x, viem 2.x, Fastify 5.x, Prisma 5.x, PostgreSQL 16, Redis 7 + BullMQ 5.x, Zod 3.x, Vitest 2.x, Hardhat + chai, Pino 9.x, ethers v6.13.x server-side only, @0glabs/0g-ts-sdk 0.3.3, @0glabs/0g-serving-broker 0.6.5.
